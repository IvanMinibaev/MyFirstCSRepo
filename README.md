Добро пожаловать в домашку по С#!

Вот инструкция, какие команды надо ввести в консоль, чтобы все заработало:

cd .\<название папки с номером задвния. Чтобы не переписывать, можно просто цифпа + tab>\
dotnet run
после исполнения программы: dotnet clean
